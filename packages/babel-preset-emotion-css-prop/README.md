# @emotion/babel-preset-emotion-css-prop

Same interface as [babel-preset-css-prop](https://github.com/emotion-js/emotion/tree/master/packages/babel-preset-css-prop).

```bash
npm install @xstyled/babel-preset-emotion-css-prop @babel/core@^7
```

The preset peers on `@babel/core` `^7`. Install that range directly. An unpinned `@babel/core` currently resolves to v8, which is outside the peer range, and Yarn 1 does not install the peer at all.

See [xstyled documentation](https://xstyled.dev)
