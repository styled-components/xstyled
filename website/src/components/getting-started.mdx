## Getting Started

### Install xstyled

```
npm install styled-components @xstyled/styled-components @xstyled/system
```

`@xstyled/system` has to be installed directly. pnpm and Yarn Plug'n'Play do not expose it just because `@xstyled/styled-components` depends on it, and the TypeScript theme setup imports it.

### Setup `theme` and `Preflight`

```js
// App.js
import {
  defaultTheme,
  ThemeProvider,
  Preflight,
} from '@xstyled/styled-components'

const theme = {
  ...defaultTheme,
  // Customize your theme here
}

export default function App() {
  return (
    <ThemeProvider theme={theme}>
      <Preflight />
      {/* ... */}
    </ThemeProvider>
  )
}
```

### Write your first component

```js
import { x } from '@xstyled/styled-components'

function Button(props) {
  return <x.button bg="blue-500" {...props} />
}
```
