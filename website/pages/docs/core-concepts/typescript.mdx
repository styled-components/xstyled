# TypeScript

Use xstyled with TypeScript.

<carbon-ad />

xstyled is written in TypeScript, all the library is strongly typed. It works out of the box for TypeScript users.

You may have to configure styled-components or Emotion, especially if you use a theme.

## Use TypeScript with Styled Components

### Install

```
npm install styled-components @xstyled/styled-components @xstyled/system
```

`@xstyled/system` has to be a direct dependency. The declaration file below imports it and augments its `Theme`. pnpm and Yarn Plug'n'Play do not expose a package to your app just because `@xstyled/styled-components` depends on it, so the import and the augmentation both fail until `@xstyled/system` is in your own `package.json`.

### Create a declaration file

```js
// styled.d.ts

// import original module declarations
import 'styled-components'
import '@xstyled/system'
import {
  ITheme,
  DefaultTheme as XStyledDefaultTheme,
} from '@xstyled/styled-components'

interface AppTheme extends ITheme, XStyledDefaultTheme {
  /* Customize your theme */
}

// and extend them!
declare module '@xstyled/system' {
  export interface Theme extends AppTheme {}
}
declare module 'styled-components' {
  export interface DefaultTheme extends AppTheme {}
}
```

Read [styled-components TypeScript guide](https://styled-components.com/docs/api#typescript) to learn more about it.

## Use TypeScript with Emotion

### Install

```
npm install @emotion/react @emotion/styled @xstyled/emotion @xstyled/system
```

`@xstyled/system` has to be a direct dependency. The declaration file below imports it and augments its `Theme`. pnpm and Yarn Plug'n'Play do not expose a package to your app just because `@xstyled/emotion` depends on it, so the import and the augmentation both fail until `@xstyled/system` is in your own `package.json`.

### Create a declaration file

```js
// styled.d.ts

// import original module declarations
import '@xstyled/system'
import '@emotion/react'
import { ITheme, DefaultTheme as XStyledDefaultTheme } from '@xstyled/emotion'

interface AppTheme extends ITheme, XStyledDefaultTheme {
  /* Customize your theme */
}

// and extend them!
declare module '@xstyled/system' {
  export interface Theme extends AppTheme {}
}
declare module '@emotion/react' {
  export interface Theme extends XStyledDefaultTheme {
    /* Customize your theme */
  }
}
```

Read [Emotion TypeScript guide](https://emotion.sh/docs/typescript) to learn more about it.
