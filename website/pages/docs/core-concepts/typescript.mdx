# TypeScript

Use xstyled with TypeScript.

<carbon-ad />

xstyled is written in TypeScript, all the library is strongly typed. It works out of the box for TypeScript users.

You may have to configure styled-components or Emotion, especially if you use a theme.

## Use TypeScript with Styled Components

### Create a declaration file

`@xstyled/styled-components` re-exports `Theme`. Augment that package, the one the install command already added.

`colors` is omitted and then intersected. Replacing the default palette outright is a type error, because the new `colors` would be missing the built-in keys.

```js
// styled.d.ts

import 'styled-components'
import {
  ITheme,
  DefaultTheme as XStyledDefaultTheme,
} from '@xstyled/styled-components'

interface AppTheme extends ITheme, Omit<XStyledDefaultTheme, 'colors'> {
  colors: XStyledDefaultTheme['colors'] & {
    brand: string
  }
}

declare module '@xstyled/styled-components' {
  export interface Theme extends AppTheme {}
}
declare module 'styled-components' {
  export interface DefaultTheme extends AppTheme {}
}
```

Read [styled-components TypeScript guide](https://styled-components.com/docs/api#typescript) to learn more about it.

## Use TypeScript with Emotion

### Create a declaration file

`@xstyled/emotion` re-exports `Theme`. Augment that package, the one the install command already added. `useTheme` from this package is Emotion's theme, so `@emotion/react` is augmented too.

`colors` is omitted and then intersected. Replacing the default palette outright is a type error, because the new `colors` would be missing the built-in keys.

```js
// styled.d.ts

import '@emotion/react'
import {
  ITheme,
  DefaultTheme as XStyledDefaultTheme,
} from '@xstyled/emotion'

interface AppTheme extends ITheme, Omit<XStyledDefaultTheme, 'colors'> {
  colors: XStyledDefaultTheme['colors'] & {
    brand: string
  }
}

declare module '@xstyled/emotion' {
  export interface Theme extends AppTheme {}
}
declare module '@emotion/react' {
  export interface Theme extends AppTheme {}
}
```

Read [Emotion TypeScript guide](https://emotion.sh/docs/typescript) to learn more about it.
